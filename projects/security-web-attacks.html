Cybersecurity / Academic project 12

Examining SQL injection and CSRF

Course web-security experiments and explanations of the associated defenses.

SQL injectionCSRFPrepared statements

What I did

Completed the supplied SQL-injection and cross-site request forgery exercises, documented attack behavior in the lab applications, and explained how prepared statements separate query code from input data.

Lab setup

I built and started the lab containers with dcbuild and dcup, then checked their status with dockps. The CSRF environment included the Elgg application, its database and an attacker website, with local hostname mappings and HTTP Header Live for observing browser requests. The SQL-injection environment used a separate vulnerable web application and MySQL database, whose tables and fields I inspected before the exercises.

Why it matters

These exercises connect application behavior to trust boundaries around database input and authenticated browser requests.

What came out of it

Produced a report with lab observations, relevant snippets and explanations of SQL-injection and CSRF mechanisms.
