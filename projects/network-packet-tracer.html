Software / Academic project 06

Configuring an addressed and routed network

Packet Tracer topology supported by an addressing and service configuration report.

Packet TracerRoutingDHCPDNS

What I did

Documented a wireless LAN, router-to-router addressing, DHCP configuration and DNS settings, and supplied the associated Packet Tracer network model.

Why it matters

Addressing, routing and name services must agree for devices to find each other and communicate across network segments.

What came out of it

Produced a network configuration report and a Packet Tracer file that can be inspected together to trace the addressing and service plan.

About this coursework
The Packet Tracer file requires Cisco Packet Tracer to open. Its simulation was not rerun during portfolio preparation.
