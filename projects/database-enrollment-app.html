Data / Academic project 18

Building a SQLite course enrollment application

Relational design and a Python command-line application for student enrollment.

PythonSQLiteRelational designParameterized queries

What I did

Defined student, course and enrollment tables and implemented a Python menu for listing and searching courses, enrolling and withdrawing students, viewing classes and deleting student records. Used SQLite queries and a composite enrollment key.

Why it matters

A relational schema connects records through explicit keys, while parameterized queries and structured menu operations make data access clearer and easier to maintain.

What came out of it

Produced a schema document, application source and SQLite database illustrating the enrollment workflow and relationships between students and courses.

The schema report credits Duy Hoang and Leighanna Navales. Original collaborator attribution is preserved.
