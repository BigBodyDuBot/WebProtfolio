Cybersecurity / Academic project 15

Testing web application defenses

SQL injection and CSRF exercises in a local teaching environment.

Web securitySQL injectionCSRF

What I did

Investigated SQL injection and cross-site request forgery in Docker-based PHP, MySQL and Elgg lab applications, and examined the behavior of CSRF token protections.

Why it matters

Separating user input from database commands and validating request intent are central to web application security.

What came out of it

Documented the lab attacks, observed behavior and relevant defenses in a report; prepared statements are discussed as a mitigation.

About this coursework
Controlled classroom applications only. Discussion of prepared statements does not imply a production remediation was implemented.
