Cybersecurity / Academic project 08

Translating access policies into Linux permissions

Least-privilege access matrices, access lists and Linux permission checks.

Least privilegeACLchmodLinux

What I did

Translated a business access-control scenario into process and file permissions, constructed an access-control matrix and access lists, and documented Linux ownership and permission commands.

Lab setup

The lab used Ubuntu Linux and a sample application directory containing configuration, analytics and deployment files. The access-control exercise represented three processes with separate user accounts and two groups, then mapped the policy to ownership and file permissions. The report records permission checks and terminal evidence, including an interruption noted during the setup.

Why it matters

Mapping policy to operating-system permissions helps ensure that each process receives the access required for its task.

What came out of it

Produced a completed lab report with permission reasoning, configuration steps and verification evidence.
