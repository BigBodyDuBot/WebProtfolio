Software / Academic project 24

Exploring process scheduling in xv6

An annotated process-management file with a shortest-burst scheduling exercise.

xv6CSchedulingProcess management

What I did

Worked with the xv6 process-management source, added scheduling-related state and a pseudo-random burst-time helper, and changed the scheduler’s selection logic to choose a runnable process with the shortest burst time.

Why it matters

Changing scheduler selection exposes the relationship between process state, locking and the policy used to choose the next runnable process.

What came out of it

Produced an annotated proc.c implementation showing the scheduling changes within the surrounding xv6 process code.

About this coursework
This is an implementation exercise supplied as one source file. The full xv6 tree, required headers and benchmark results were not supplied, so it is not presented as a standalone runnable system.

The file retains the original xv6 framework code and comments; the project represents modifications within that framework.
