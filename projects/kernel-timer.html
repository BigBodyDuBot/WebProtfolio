Inside a Linux kernel module

A C timer module with a counter and a /proc interface.

CLinuxKernel modules

What I did

Developed coursework in C using kernel timers, jiffies, logging and a /proc interface to expose a counter.

Why it matters

Kernel modules illustrate how low-level code interacts with the operating system beyond a normal user-space program.

What came out of it

Produced source files and a report documenting the timer and counter behavior as an educational systems project.

About this coursework
Educational source code; not a production driver. The portfolio does not execute kernel modules in the browser.
