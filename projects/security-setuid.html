Cybersecurity / Academic project 09

Investigating environment variables and Set-UID

Controlled experiments on inherited environment settings and privileged programs.

Set-UIDEnvironment variablesforkexec

What I did

Changed shell environment variables and examined their inheritance through fork and exec. Investigated how PATH, dynamic loading and program invocation affect Set-UID behavior in the supplied lab environment.

Lab setup

The lab used a Linux shell and small C programs to examine environment inheritance and privileged execution. I compiled the test programs, compared parent and child environments, and configured a root-owned Set-UID executable for the privilege tests. PATH, LD_LIBRARY_PATH and a custom variable provided controlled inputs for comparing how each program received its environment. The downloadable folder includes the C programs supplied for the environment-variable and Set-UID exercises.

Why it matters

Environment settings can influence privileged execution. Understanding those boundaries supports safer choices when launching commands from programs.

What came out of it

Produced a screenshot-supported report explaining the observed behavior of environment inheritance and Set-UID experiments.
