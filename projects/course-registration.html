Data / Academic project 06

A small course registration database

A Python and SQLite system for students, courses and enrollments.

PythonSQLiteRelational design

What I did

Implemented database tables and Python operations for registration, course lookup, enrollment, withdrawal and enrollment counts, using parameterized SQL queries and relational joins.

Why it matters

Separating students, courses and enrollments keeps the data organized and supports queries across related records.

What came out of it

Produced a working educational database project, notebooks and a final report using a small sample dataset to demonstrate the registration workflow.

About this coursework
Classroom prototype with sample data; not a deployed student-information system.

The final report lists Duy Hoang and Leighanna Navales. Original report credits are retained.
