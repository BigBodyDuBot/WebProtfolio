Software / Academic project 05

Building a TCP web server and client

Python socket programs that exchange HTTP requests and serve an HTML page.

PythonTCP socketsHTTP

What I did

Completed a Python server that accepts a TCP connection, parses a requested path, sends an HTTP response with headers and returns a 404 response for a missing file. Wrote a client that sends a GET request and collects the response.

Why it matters

Implementing both sides exposes how sockets, requests, headers and file handling fit together beneath a browser request.

What came out of it

Produced server and client source files plus a small HTML test page demonstrating the components of a sequential HTTP exchange.

About this coursework
This is a local course exercise with a sequential server, rather than a production web server.

The server retains the original course scaffold and fill-in markers.
