Cybersecurity / Academic project 11

Exploring packet spoofing and firewall rules

Docker-based network experiments using packet tools and iptables.

DockerScapyiptablesConnection tracking

What I did

Configured the course container network, captured and generated packets, and tested stateless and stateful firewall rules. Documented connection tracking, traffic limits and load-balancing experiments.

Lab setup

I built and started the Docker Compose environment from the Labsetup folder. The packet experiments used an attacker container and two hosts on the same virtual network; the firewall experiments added a router between the internal and external networks. I checked container status with dockps, entered the attacker and router containers with docksh, and used packet tools and iptables to observe traffic and rule behavior. The downloadable folder contains the packet sniffing and spoofing environment.

Why it matters

Packet-level observations show how network controls handle traffic and how rule placement and connection state affect communication.

What came out of it

Produced a combined report with setup evidence, command and code explanations, rule behavior and screenshots of the network experiments.
